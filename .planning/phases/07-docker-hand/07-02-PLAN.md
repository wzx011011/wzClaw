  <action>
    创建 `packages/hand/Dockerfile`，参考 relay/Dockerfile 的简洁模式（Hand 不需要 better-sqlite3 等 native binding）：

    **Dockerfile（两阶段构建）**:
    ```
    # Stage 1: 安装依赖 + 编译
    FROM node:20-alpine AS builder
    WORKDIR /app
    COPY package*.json ./
    COPY tsconfig.json ./
    COPY src/ src/
    COPY tools/ tools/
    COPY docker-entry.ts ./
    RUN npm install && npm run build

    # Stage 2: 最小运行时
    FROM node:20-alpine
    WORKDIR /app
    COPY --from=builder /app/dist ./dist
    COPY --from=builder /app/node_modules ./node_modules
    ENV NODE_ENV=production
    CMD ["node", "dist/docker-entry.js"]
    ```
    - 不需要 python3/make/g++（无 native binding）
    - 不需要 EXPOSE（出站 WebSocket 连接，不监听端口）
    - 不需要 USER node（单进程简单容器，但加上也无妨）
    - 不需要 /data 目录创建（通过 volume 挂载）

    创建 `packages/hand/docker-compose.hand.yml`:
    ```yaml
    version: "3.8"
    services:
      docker-hand:
        build:
          context: .
          dockerfile: Dockerfile
        container_name: wzxclaw-docker-hand
        restart: unless-stopped
        environment:
          - SERVER_URL=ws://agent-server:8082/
          - AUTH_TOKEN=${AUTH_TOKEN}
        volumes:
          - /nas-data:/data
        depends_on:
          - agent-server
        networks:
          - wzxclaw

      agent-server:
        image: wzxclaw-agent-server
        container_name: wzxclaw-agent-server
        networks:
          - wzxclaw

    networks:
      wzxclaw:
        external: true
    ```
    - `SERVER_URL` 使用 Docker 网络内的 service name `agent-server` 而非 localhost
    - `/nas-data:/data` 挂载 NAS 数据卷（按实际 NAS 路径调整）
    - `wzxclaw` 外部网络与 agent-server 共享
    - 备选方案: 如果 agent-server 已经用 `--network host` 运行，则 docker-hand 也用 host 网络，SERVER_URL 设为 `ws://localhost:8082/`
    - 在 docker-compose.hand.yml 文件顶部加注释说明两种网络配置方式

    创建 `packages/hand/.dockerignore`:
    ```
    node_modules
    dist
    *.test.ts
    vitest.config.ts
    .git
    .gitignore
    *.md
    ```

    **注意**: docker-compose.hand.yml 中的 `agent-server` service 定义是参考用的 — 实际部署时 agent-server 可能已经在单独的 docker-compose 中运行。文件顶部注释中说明如何与现有 agent-server 部署集成。同时提供 `network_mode: host` 的备选配置（注释掉），方便用户根据实际 NAS 环境选择。
