  <behavior>
    - FileRead: 读取存在的文件返回内容（带行号），不存在的文件返回 isError，startLine/endLine 截取行范围，encoding 参数可选
    - FileWrite: 写入内容到文件返回字节数，createDirs=true 自动创建父目录，append=true 追加而非覆盖
    - FileList: 列出目录返回 JSON 数组 [{name,path,size,isDir,modified}]，recursive=true 递归子目录，不存在目录返回 isError
    - ShellExecute: 执行命令返回 {stdout,stderr,exitCode}，超时 30s 默认，禁止 rm -rf / 等危险命令，cwd 默认 /data
  </behavior>
  <action>
    在 `packages/hand/tools/` 目录下创建四个工具文件，每个工具实现 `HandTool` 接口（从 `../src/tool-executor.js` 导入）。

    **FileRead (`file-read.ts`)**:
    - 使用 `node:fs/promises` 的 `readFile` 读取文件
    - 支持 `encoding` 参数（默认 `utf-8`）
    - 支持 `startLine` / `endLine` 行号范围：读取后按 `\n` split，slice 后重新 join
    - 输出带行号格式（`1: content`），与桌面端 Read 工具风格一致
    - 文件不存在或无权限返回 `{output: error.message, isError: true}`

    **FileWrite (`file-write.ts`)**:
    - 使用 `node:fs/promises` 的 `writeFile` / `appendFile`
    - `createDirs=true` 时先调用 `mkdir` with `{recursive: true}` 创建父目录
    - `append=true` 使用 `appendFile`，否则 `writeFile`
    - 返回 `Successfully wrote {N} bytes to {path}`
    - 目标路径在 context.workingDirectory 之外时返回警告但仍然执行（容器内无严格路径限制）

    **FileList (`file-list.ts`)**:
    - 使用 `node:fs/promises` 的 `readdir` with `{withFileTypes: true}`
    - 对每个 entry 获取 `stat` 提取 size 和 mtime
    - `recursive=true` 时递归子目录
    - `pattern` 参数支持简单 glob（使用 `path.basename().match()` 实现最小 glob）
    - 输出 JSON.stringify 的数组

    **ShellExecute (`shell-execute.ts`)**:
    - 使用 `node:child_process` 的 `exec`（通过 `promisify` 包装）
    - `timeout` 参数默认 30 秒，传递给 exec 的 timeout 选项
    - `cwd` 参数默认 `/data`（NAS 挂载卷）
    - 安全检查: 在执行前检查 command 是否匹配危险模式（`rm -rf /`, `mkfs`, `dd if=`, `:(){ :|:& };:`），匹配则拒绝执行
    - 输出 JSON `{stdout, stderr, exitCode}`
    - exec 超时时 stderr 包含 "Command timed out after {N}s"

    **`tools/index.ts`**: barrel export 四个工具类 + `createNasTools()` 工厂函数返回 HandTool 数组。

    **测试文件**: 每个工具一个测试文件，使用 `os.tmpdir()` 或 `vitest` 提供的临时目录（`mkdtemp`）创建测试文件和目录。ShellExecute 测试使用安全命令（`echo`, `ls`, `pwd`）。每个测试文件覆盖正常路径 + 错误路径 + 边界情况。

    **tsconfig.json 修改**: 在 `packages/hand/tsconfig.json` 中确保 `tools/` 和 `docker-entry.ts` 包含在编译范围内（当前 `src/**/*.ts` 配置可能不覆盖 tools/，需要将 include 改为 `["src/**/*.ts", "tools/**/*.ts", "docker-entry.ts"]`）。

    所有代码注释使用中文。文件头部统一加 `// ============================================================` 注释块。

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NAS Hand → NAS 文件系统 | Hand 工具以容器内用户身份操作挂载卷 |
| NAS Hand → agent-server | localhost WebSocket，同宿主机信任 |
| Brain → NAS Hand | Brain 路由工具调用到 Docker Hand，信任 Hand 执行结果 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | E (Elevation) | ShellExecute | mitigate | 危险命令黑名单检查（rm -rf /, mkfs, dd if=），阻止容器级破坏 |
| T-07-02 | T (Tampering) | FileWrite | accept | 容器隔离，写入仅影响挂载卷；NAS 卷本身有 NAS 级权限控制 |
| T-07-03 | I (Info Disclosure) | FileRead | accept | 只能读取挂载卷内文件，容器外数据不可达 |
| T-07-04 | D (DoS) | ShellExecute | mitigate | 30 秒超时限制防止单次命令占用资源 |
| T-07-05 | S (Spoofing) | docker-entry | mitigate | AUTH_TOKEN 认证，无 token 无法注册 Hand |
</threat_model>
